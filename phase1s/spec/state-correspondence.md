# SRW3 Phase 1S — The State Correspondence (spec/state-correspondence.md)

Status: the formal definitions of record for mission §2. Everything here is
defined mechanically in `phase1s/semantics/rel-machine.k` (generated by
`phase1s/scripts/make_rel_1s.py`; regenerate, never edit). The two models:

* **The constructor-count model (the 1R model of record).** `AStateQ`,
  `absStQ(TG, C, T, G, E, N, SF, D)` with `G, E : PoolCount`,
  `PoolCount ::= zeroP | succP(_)`, step `absStepQ`, invariant `ABSInvQ`
  (tag-1 conjuncts `C ∧ T ∧ SF` — the pool conjuncts were REMOVED in 1Q:
  structural nonnegativity is obligation C1, not invariant content),
  coherence `tagCoherentQ`, domain `absExecutableQ`, fold `absRunFQ`,
  runner rules over `<srw3closureJ>`.
* **The integer model (the 1P model of record, in-repo image).**
  `AStateQE`, `absStQE(C, T, G', E', N, SF, D)` with `G', E' : Int`, step
  `absStepE` (the frozen 1P `absStepT` rows verbatim, renamed, tag literals
  replaced by the bit literals they were pinned with), invariant `ABSInvE`
  (the 1P `ABSInvT` meaning verbatim — INCLUDING the tag-1 nonnegativity
  conjuncts `G' >=Int 0 ∧ E' >=Int 0`, i.e. the integer model's actual
  safety predicate), tag `branchTag(C, T) ∈ {0, 1}`.

Provenance of the integer side: the QS module declares the mirror itself
(§G of the frozen file); a direct dual import of the two frozen modules is
infeasible on the pinned frontend (token ambiguities —
`audit/frontend-probes-1s.md` Probe A). The mirror↔1P correspondence is
carried by (i) the 1Q generator's verbatim transcription discipline, (ii)
the sha256 anchors of both frozen sources, and (iii) the static row-witness
`scripts/verify_rows_1s.py` (fail-closed). The transcription check is
Python-side and is **disclosed as trusted computing base (TCB-1)** — see §5.

## §1 CountRel — the count-level representation relation

```
syntax Bool ::= CountRel ( PoolCount , Int ) [function, total]
rule CountRel(P:PoolCount, I:Int) => I ==Int countToInt(P)
```

`CountRel(p, n)` holds iff the integer `n` is EXACTLY the interpretation
`countToInt(p)` of the constructor count `p` — no slack, no bound, no
"up-to" approximation. `countToInt` is the frozen 1Q definition
(`countToInt(zeroP) = 0`, `countToInt(succP(p)) = countToInt(p) + 1`).

* The ⧸⧸ "no legal natural number is missed" direction (the rebuild
  `Int → PoolCount`) is deliberately NOT defined — it would need integer
  induction; the converse-direction obligation (mission §4) is therefore
  discharged only on the evaluated fragment (see §4 of this spec and the
  converse battery).
* `countToInt(p) >=Int 0` for ALL `p : PoolCount` is obligation **C1.2**
  (`spec/count-semantics.md`): on this toolchain it is NOT mechanically
  provable (the structural-induction-over-function-argument boundary
  recorded since 1O) and is NEVER silently assumed — every claim that
  depends on it carries the dependence in its label and classification.

## §2 StateRel — the full-state representation relation

```
syntax Bool ::= StateRel ( AStateQ , AStateQE ) [function, total]
rule StateRel(absStQ(TG:Int, C:Bool, T:Bool, G:PoolCount, E:PoolCount,
                     N:Int, SF:Bool, D:ADiag),
              absStQE(C, T, G2:Int, E2:Int, N,
                      SF, D))
  => CountRel(G, G2) andBool CountRel(E, E2)
     andBool TG >=Int 0 andBool TG <=Int 1
     andBool (TG ==Int 1 impliesBool (C  andBool T ))
     andBool (TG ==Int 0 impliesBool (notBool C andBool notBool T))
```

The shared fields C, T, N, SF, D are written IDENTICALLY in both patterns:
the field equalities (a)-(c) are enforced at MATCH time by the K unifier —
the reliable route on this toolchain. (The frontend probes found that
`==Bool` equality CONJUNCTIONS over shared symbolic variables inside a
function RHS are unsound to rely on here: single equalities close while
two-member conjunctions leave polluted bindings — `probe_k2`/`probe_j`
logs under `transcripts/probes/`. The matcher route avoids the class
entirely.) Since the mirror's bits ARE the shared C, T, one conjunct set
governs the tag↔bits consistency on BOTH sides (e); the range conjunct
(e0) refuses incoherent tags explicitly.

Field-by-field disclosure (mission §2's "no silent field drops, no
weakened safety predicates"):

| field (Q) | field (Int mirror) | condition | comment |
|---|---|---|---|
| `TG:Int` | `branchTag(C2,T2)` (implicit) | (e) | the Int mirror HAS no tag field — its branch is the bit pair; the Q tag must equal `branchTag` of the related bits on the coherent fragment; both sides' consistency conjuncts are explicit |
| `C, T` (config / auth pins) | `C2, T2` | (a) equal | the authorization-relevant branch bits are shared structure |
| `N` (slot counter) | `N2` | (a) equal | shared bookkeeping |
| `SF` (safety flag) | `SF2` | (b) equal, identity mapping | the safety-relevant flag is NOT discarded and NOT reinterpreted |
| `D : ADiag` | `D2` | (c) equal, identity mapping | all four diagnostic constructors carried |
| `G, E : PoolCount` | `G2, E2 : Int` | (d) CountRel | exact interpretation; **no** `>=Int 0` conjunct is ADDED here — the integer side's own nonnegativity stays inside `ABSInvE` (the integer model's actual predicate), and the constructor side's nonnegativity is C1.2, never a silent weakening or strengthening |

The relation is deliberately defined as a CONJUNCTIVE Boolean function
(total, decidable on ground terms by evaluation) — no disjunction at the
top, no `if-then-else` — per the house soundness discipline (the 1P/1Q
conjunctive-invariant lesson).

## §3 The definitional image and the initial correspondence

```
syntax AStateQE ::= qToQE ( AStateQ ) [function, total]
rule qToQE(absStQ(_:Int, C:Bool, T:Bool, G:PoolCount, E:PoolCount,
                  N:Int, SF:Bool, D:ADiag))
  => absStQE(C, T, countToInt(G), countToInt(E), N, SF, D)
```

* **Image lemma** (`1S-STATEREL-IMAGE`): `StateRel(SQ, qToQE(SQ))` for
  coherent `SQ`. DISPOSITIONS: the GENERAL form (symbolic tag) is an
  ATTEMPT — the residual is the implication checker's leaf propagation
  (neither a `tagCoherentQ` hypothesis nor its unfolded conjuncts propagate
  into the goal's `impliesBool` conjuncts; log retained). The two
  CONSTRUCTOR-PINNED cases `1S-STATEREL-IMAGE-T0` / `-T1` (rc=0 each) close
  fully by evaluation and carry the lemma's content on the coherent
  fragment — the only fragment any reachable state inhabits (the 1Q COH
  record). The coherence hypothesis is load-bearing only for the tag-bits
  conjuncts.
* **Initial-state correspondence** (`1S-INIT-CORR`): the two genesis
  states are related and safe on both sides:
  `StateRel(absGenesisQ, eraseQ(absGenesisQ))` (evaluation),
  `ABSInvQ(absGenesisQ)` (the 1Q record), and
  `ABSInvE(eraseQ(absGenesisQ))` — the integer initial-safety of record
  (`InitialSafeInt`), closing by evaluation: the genesis counts are
  `zeroP`, interpreted `0`, and every `ABSInvE` conjunct evaluates true.
* **Safety predicates, kept separate (mission §6's five states):**
  - `SafeCountQ(SQ)  := ABSInvQ(SQ)` — the constructor-count model's safety.
  - `SafeIntQ(SQ)    := ABSInvE(eraseQ(SQ))` — the integer safety PREDICATE
    evaluated on the Q-state's image (the migration target, stated over
    the Q runner).
  - `SafeIntE(SE)    := ABSInvE(SE)` — the integer model's own safety.
  The ledger never identifies these three; `1R-UNIV-COMPOSED-QS` proves the
  first; the migration attempts the second; the third is the 1P meaning of
  record. "Full representation equivalence", "concrete-implementation
  correspondence", and "actual protocol-commitment-boundary safety" are
  NOT claimed by any 1S claim row.

## §4 Domain restrictions, stated precisely (mission §4's allowance)

* The correspondence claims are restricted to the COHERENT fragment
  (`tagCoherentQ`): on incoherent tags (`TG >=Int 2` or `TG <=Int -1`) the
  Q step's `[owise]` complement stutters while the integer mirror is STUCK
  on mixed bits (`branchTag(true,false)` has no rule — the row cannot
  fire). The two models therefore INTENTIONALLY differ on incoherent
  states; the difference is stated here and every §4 claim carries the
  coherence hypothesis explicitly. No reachable state is incoherent (the
  1Q COH battery; re-anchored in `n_s_coverage.k` as the inertness cell).
* Mixed-bit mirror states (`C ≠ T`) are stuck on the integer side BY
  CONSTRUCTION (the verbatim 1P rows pattern both bits); the stuckness is
  witnessed by a MUST-FAIL ground claim, never asserted positively.
* The pre-init exec class: the Q machine's stall row (identity) and the
  integer mirror's stall row (identity) agree; the executable-domain
  discipline (`absExecutableQ` = false for a pre-init exec head) keeps
  such runs OUTSIDE every universal claim, on both models (the integer
  side inherits the domain through the lockstep, disclosed in
  `spec/transition-coverage.md` §4).

## §5 The converse direction and the TCB statement

* Converse (Int → Q) on the GENERAL nonneg fragment requires the rebuild
  `Int → PoolCount` and integer induction — NOT defined, NOT attempted as
  a theorem. The converse battery discharges the BOUNDED form: for every
  concrete related state in the depth-0..3 family, an explicit Q witness
  satisfying `StateRel` closes by evaluation (`1S-CONV-*` rows,
  BOUNDED-PROVED). The general converse is recorded as OPEN with the exact
  boundary (the same structural/integer-induction frontier as C1.2).
* **TCB-1 (disclosed):** the mirror↔1P row correspondence is verified by
  the static Python witness, not by a K theorem. What the witness checks
  externally: every `absStepE` row of the frozen QS module corresponds
  row-by-row to an `absStepT` row of the frozen 1P TDRR file under the
  documented renames; `ABSInvE` ≡ `ABSInvT` modulo the same renames; the
  command syntax is shared. What no 1S claim relies on beyond the in-repo
  functions: nothing — every proof battery uses ONLY the frozen QS
  module's own functions (`absStepQ`, `absStepE`, `ABSInvQ`, `ABSInvE`,
  `eraseQ`, `countToInt`).
* **Not a bisimulation (mission §4's wording discipline):** the §4 results
  establish a ONE-DIRECTIONAL forward simulation of the integer model by
  the constructor-count model along the shared command sequences
  (`StateRel(sQ,sE) ∧ StepPool(sQ,c,sQ') ⇒ ∃ sE'. StepInt(sE,c,sE') ∧
  StateRel(sQ',sE')` — in fact the functional, deterministic form:
  `sE' = absStepE(sE, c)`), RESTRICTED to the coherent fragment. The word
  "bisimulation" is never used of these results: the converse direction
  holds only on the evaluated fragment, and the incoherent fragments
  diverge by design.
